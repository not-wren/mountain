# mountain
climbing it

A collection of media which revolve around mountains + a short saying (poem?). The Climber, A Short Hike, Peak, Cairin, and Celeste are the media in order of left to right. I really like the poem, and honestly a simpler website helps keep the focus on words and images instead of movement and user interaction.


This project took me super long even though it looks relatively simple.

1. I spent ~45 to an hour minutes looking for a bug and fixing code that turned out to be accidentally adding a space between . and #

2. I attempted to add code to create a semi-tranparent overlay with text when the mouse hovered over the images, however it kept breaking the website. This took about 2-3 hours unfortunately and I gave up when I realized I would have to create the div and hover animations for each image, so six times (on top of the hours I spent on trying to get one image to work). This to me was not worth it.

Hopefully I'll be able to implement the hover feature in a future website though! I'm still proud of how this website came out. I used HTML and CSS for this. also very winter-coded (heh get it) website with all the snow
